KEY FILES TO CONFIGURE
================================================================================

1. Database Configuration (3 files):
   - admin/vendor/inc/config.php
   - tech/vendor/inc/config.php
   - usr/vendor/inc/config.php
   
   Update these with your database credentials:
   $dbuser = "root";
   $dbpass = "";
   $host = "localhost";
   $db = "electrozot_db";

2. Database Import:
   - Import: DATABASE FILE/electrozot_db_complete.sql
   - Database name: electrozot_db

================================================================================
TROUBLESHOOTING
================================================================================

Issue: Cannot login
Solution: Check database credentials in config.php files

Issue: Upload fails
Solution: Check directory permissions (should be 777)

Issue: White screen
Solution: Enable PHP error display, check error logs

Issue: Database errors
Solution: Re-import electrozot_db_complete.sql

Issue: Notifications not working
Solution: Check tms_admin_notifications table exists
