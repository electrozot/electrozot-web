TROUBLESHOOTING
---------------
If you encounter issues:

1. Login not working?
   - Check database credentials in admin/vendor/inc/config.php
   - Verify admin user exists in tms_admin table
   - Clear browser cache and cookies

2. White screen after login?
   - Check PHP error logs
   - Verify all database columns exist
   - Ensure session is working

3. Upload fails?
   - Check directory permissions (should be 777)
   - Verify PHP upload settings in php.ini
   - Check disk space
