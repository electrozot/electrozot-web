DATABASE SETUP
--------------
1. Import: DATABASE FILE/electrozot_db_complete.sql
2. This creates all tables, triggers, views, and sample data

ADMIN LOGIN
-----------
URL: http://localhost/your-project/admin/
Email: mohit@electrozot.in
Password: mohit@123

If login fails, run: http://localhost/your-project/admin/FIX-LOGIN-NOW.php
Then DELETE FIX-LOGIN-NOW.php after successful login

DATABASE CONNECTION
-------------------
File: admin/vendor/inc/config.php
Default settings:
  - Host: localhost
  - User: root
  - Password: (empty)
  - Database: electrozot_db

KEY FEATURES
------------
✓ Booking management system
✓ Technician assignment with skill matching
✓ Real-time notifications
✓ User data protection (cannot delete users)
✓ Booking limit system (technicians can handle multiple bookings)
✓ Admin price management
✓ ID card generation for technicians
✓ Automated status updates

IMPORTANT FILES
---------------
- admin/index.php - Admin login
- admin/admin-dashboard.php - Main dashboard
- admin/auto-setup-services.php - Auto-creates services on first login
- admin/auto-fix-technician-slots.php - Auto-syncs technician data

TROUBLESHOOTING
---------------
White page on login? Check:
1. Database exists and is imported
2. Database credentials in config.php are correct
3. Admin user exists (run FIX-LOGIN-NOW.php)
4. PHP errors enabled: error_reporting(E_ALL)
