🔒 MANUAL LOCK FEATURE
Lock technician accounts immediately for unpaid charges

───────────────────────────────────────────────────────────────
📍 WHERE TO FIND IT
───────────────────────────────────────────────────────────────

Option 1: Record Payment Page
URL: admin/admin-record-commission-payment.php
Look for: RED CARD at bottom (Manual Lock for Unpaid Charges)

Option 2: Pending Commissions Page (FASTER!)
URL: admin/admin-pending-commissions.php
Look for: RED "LOCK" BUTTON next to each technician


───────────────────────────────────────────────────────────────
⚡ QUICK LOCK (Fastest Method)
───────────────────────────────────────────────────────────────

1. Open: admin/admin-pending-commissions.php
2. Find technician with pending payment
3. Click RED "Lock" button
4. Confirm popup
5. ✅ DONE! Account locked immediately


───────────────────────────────────────────────────────────────
📝 DETAILED LOCK (More Control)
───────────────────────────────────────────────────────────────

1. Open: admin/admin-record-commission-payment.php
2. Scroll to RED CARD (Manual Lock section)
3. Fill in:
   ├─ Technician: Select from dropdown
   ├─ Amount Due: Enter ₹ amount
   ├─ Lock Date: Usually yesterday
   └─ Notes: Optional reason
4. Click "Lock Account Now"
5. Confirm popup
6. ✅ DONE! Account locked


───────────────────────────────────────────────────────────────
⚠️ WHAT HAPPENS WHEN LOCKED
───────────────────────────────────────────────────────────────

✗ Cannot receive new bookings
✗ Shows lock screen on login
✗ Displays amount due
✗ Must pay to unlock
✓ Logged in system


───────────────────────────────────────────────────────────────
🔓 HOW TO UNLOCK
───────────────────────────────────────────────────────────────

When Technician Pays:
1. Open: admin/admin-record-commission-payment.php
2. Use GREEN CARD (Record Payment)
3. Enter payment details
4. Submit
5. ✅ Auto-unlocks!

Manual Unlock (No Payment):
1. Open: admin/admin-unlock-technician.php
2. Click "Unlock" button
3. ✅ Unlocked


───────────────────────────────────────────────────────────────
💡 WHEN TO USE MANUAL LOCK
───────────────────────────────────────────────────────────────

✓ Technician refuses to pay
✓ Need immediate action (don't wait for 7 AM)
✓ Multiple days unpaid
✓ Technician avoiding payment
✓ Policy enforcement needed


───────────────────────────────────────────────────────────────
🔍 VERIFY LOCK WORKED
───────────────────────────────────────────────────────────────

Method 1: Check Locked List
Go to: admin/admin-unlock-technician.php
Should see technician in list

Method 2: Try Assign Booking
Go to: admin/admin-assign-technician.php
Try to assign → Should show "LOCKED" error


───────────────────────────────────────────────────────────────
📊 COMPARISON
───────────────────────────────────────────────────────────────

MANUAL LOCK              AUTO LOCK (7 AM)
├─ Immediate             ├─ Daily at 7 AM
├─ Admin decides         ├─ System checks all
├─ Admin enters amount   ├─ System calculates
├─ Can add notes         ├─ Standard message
└─ Use when urgent       └─ Automatic daily

───────────────────────────────────────────────────────────────
