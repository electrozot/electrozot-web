===============================================
AUTOMATED TECHNICIAN ACCOUNT LOCKING SYSTEM
For Unpaid Daily Commission
===============================================

HOW IT WORKS:
-------------
1. Every day at 7:15 AM, system checks yesterday's commission payments
2. If technician worked yesterday but didn't pay commission → Account LOCKED
3. Technician cannot access dashboard until payment is confirmed
4. Admin confirms payment → Account automatically UNLOCKED

TIMELINE:
---------
Work Day: Technicians complete jobs and earn commission
End of Day - 7:00 AM: Grace period for technicians to pay
7:15 AM: Automated script runs and locks unpaid accounts
Anytime: Admin can unlock after confirming payment

FILES CREATED:
--------------
1. admin/cron-lock-unpaid-technicians.php - Automated locking script
2. tech/check-account-status.php - Dashboard access control
3. admin/admin-unlock-technician.php - Manual unlock page
4. admin/admin-quick-record-payment.php - Updated to auto-unlock

SETUP INSTRUCTIONS:
-------------------

STEP 1: Setup Automated Cron Job
---------------------------------

For Linux/Mac:
1. Open terminal
2. Type: crontab -e
3. Add this line:
   15 7 * * * php /path/to/admin/cron-lock-unpaid-technicians.php

For Windows Task Scheduler:
1. Open Task Scheduler
2. Create Basic Task
3. Name: "Lock Unpaid Technicians"
4. Trigger: Daily at 7:15 AM
5. Action: Start a program
6. Program: C:\xampp\php\php.exe
7. Arguments: C:\path\to\admin\cron-lock-unpaid-technicians.php

STEP 2: Add Account Check to Technician Dashboard
--------------------------------------------------

Add this line at the TOP of these files (after session_start and config):

tech/tech-dashboard.php:
<?php include('check-account-status.php'); ?>

tech/tech-view-bookings.php:
<?php include('check-account-status.php'); ?>

tech/tech-profile.php:
<?php include('check-account-status.php'); ?>

(Add to ALL technician dashboard pages)

STEP 3: Test the System
------------------------

Manual Test:
1. Go to: admin/cron-lock-unpaid-technicians.php in browser
2. Check if accounts are locked correctly
3. Try logging in as locked technician
4. Should see "Account Locked" page

ADMIN WORKFLOW:
---------------

Daily Morning (After 7:15 AM):
1. Check admin-unlock-technician.php
2. See list of locked technicians
3. Technician calls and confirms payment
4. Two ways to unlock:
   a) Click "Unlock" button on unlock page
   b) Record payment on stats page (auto-unlocks)

TECHNICIAN EXPERIENCE:
----------------------

If Payment NOT Done:
1. Tries to login after 7:15 AM next day
2. Sees "Account Locked" screen
3. Message shows:
   - Date of unpaid commission
   - Amount owed
   - Instructions to pay and call admin
4. Cannot access any dashboard pages

After Payment:
1. Calls admin
2. Admin confirms payment
3. Account unlocked immediately
4. Can access dashboard normally

TROUBLESHOOTING:
----------------

If cron job doesn't run:
- Check cron is enabled
- Check PHP path is correct
- Check file permissions
- Run manually first to test

If technician still can access:
- Make sure check-account-status.php is included
- Check database column exists
- Clear browser cache

MANUAL OPERATIONS:
------------------

To manually lock a technician:
UPDATE tms_technician 
SET account_locked = 1, 
    lock_reason = 'Your reason here', 
    locked_at = NOW() 
WHERE t_id = [technician_id];

To manually unlock:
UPDATE tms_technician 
SET account_locked = 0, 
    lock_reason = NULL, 
    locked_at = NULL 
WHERE t_id = [technician_id];
