  BOOKING ALERT SYSTEM - Simple & Clean
═══════════════════════════════════════════════════════════

📋 WHAT IT DOES:
   Alerts when bookings need action (12+ or 25+)
   Counts: Pending, Rejected, Not Done, Unassigned
   Plays sound every 3 seconds until dismissed

📁 FILES (Only 2 files):
   ✓ booking-alert-system.php  - Logic
   ✓ booking-alert-modal.php   - Display & Sound

🔧 INTEGRATED IN:
   vendor/inc/nav.php (works on ALL admin pages)

⚙️ HOW IT WORKS:
   • 12+ bookings = Warning (yellow)
   • 25+ bookings = Critical (red)
   • Auto-resets when count < 5
   • Sound: vendor/sounds/arived.mp3
