HOW TO UPDATE YOUR DATABASE:
================================================================================

OPTION 1 - For Existing Database (Recommended):
   1. Open browser: http://localhost/ez/electrozot/update-database.php
   2. This will add missing tables/columns without losing data
   3. Delete update-database.php after running

OPTION 2 - Fresh Installation:
   1. Drop existing database (WARNING: This deletes all data!)
   2. Import: DATABASE FILE/electrozot_db_complete.sql
   3. This creates everything from scratch
