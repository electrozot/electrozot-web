QUICK START
================================================================================

1. IMPORT DATABASE
   - Open phpMyAdmin
   - Create database: electrozot_db
   - Import: DATABASE FILE/electrozot_db_complete.sql

2. CONFIGURE DATABASE
   Edit these 3 files with your database credentials:
   - admin/vendor/inc/config.php
   - tech/vendor/inc/config.php
   - usr/vendor/inc/config.php

3. SET PERMISSIONS
   Ensure these directories are writable (777):
   - admin/vendor/img/slider/
   - admin/vendor/img/gallery/
   - uploads/ (and all subdirectories)

4. ACCESS ADMIN PANEL
   URL: http://localhost/electrozot/admin/

   Password: mohit@123
