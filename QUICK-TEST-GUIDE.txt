🔓 ADMIN UNLOCK PROCESS:

   1. Technician pays commission
   2. Technician calls admin
   3. Admin verifies payment
   4. Admin goes to: admin-unlock-technician.php
   5. Admin clicks "Unlock" button
   6. Technician can work again immediately

⚙️ SETUP AUTOMATIC 7 AM EXECUTION:

   Windows Task Scheduler:
   
   1. Win+R → taskschd.msc → Enter
   2. Create Basic Task
   3. Name: "Electrozot Auto-Lock Technicians"
   4. Trigger: Daily at 7:00 AM
   5. Action: Start a program
   6. Program: C:\xampp\php\php.exe
   7. Arguments: [Full path to]\cron-lock-unpaid-technicians.php
   8. Save
